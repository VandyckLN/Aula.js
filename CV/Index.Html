Sobre Mim

Estudante de Análise e Desenvolvimento de Sistemas na Estácio, apaixonado por tecnologia e programação. Possuo sólida base em lógica de programação, com proficiência em JavaScript (Node.js), bancos de dados relacionais (SQL) utilizando MySQL e SQL Server. Experiência em desenvolvimento web com HTML5 e CSS3, além de conhecimento em linguagens como C e Python. Utilizo ferramentas de versionamento de código como Git e compartilho meus projetos no GitHub. Busco oportunidades para aplicar meus conhecimentos em projetos desafiadores e colaborar em equipes dinâmicas. Aberto a novas tecnologias e disposto a aprender continuamente.

Gerador de Senhas

O "Gerador de Senhas Seguras" é uma ferramenta web projetada para simplificar a criação de senhas robustas e personalizadas. Diga adeus às senhas fracas e vulneráveis! Com este gerador, você tem o controle total sobre a segurança das suas contas online.
